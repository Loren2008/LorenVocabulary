# Changelog

All notable project changes are documented here. The format follows Keep a Changelog principles; versions use semantic versioning where releases are published.

## [Unreleased]

### Added

- Public project documentation, contribution policy, security policy, CI, and issue templates.
- Example API configuration and a documented SQLite schema.

### Changed

- Local API credentials are no longer copied into the application bundle.
- A full local dictionary database is optional at build time.

## [1.0.0] - 2026-07-22

### Added

- Native macOS selected-text lookup with a double-Control shortcut.
- Main dictionary window, saved words, pronunciation, and flashcard review.
- Optional SQLite lookup with direct entries and inflection aliases.
- Stable local development signing workflow.
